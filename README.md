# Physics-Informed Neural Networks (PINNs)

This repository contains my implementations and experiments with
Physics-Informed Neural Networks (PINNs) for solving forward and
inverse partial differential equation (PDE) problems.

The main focus is on applications in mechanical engineering,
computational mechanics, and physics-based modeling.

## Objectives

- Develop a strong understanding of Physics-Informed Neural Networks
- Solve forward PDE problems using PINNs
- Explore inverse PDE problems and parameter identification
- Study advanced PINN methodologies
- Compare PINNs with conventional numerical methods
- Explore physics-informed machine learning for engineering applications
